🚨 TROUBLESHOOTING:

   Payment not working?
   → Check both .env files have SAME key ID
   → Restart both servers
   → Refresh browser (Ctrl + R)
   → Clear browser cache

   CORS error?
   → Check server/.env has CLIENT_URL=http://localhost:5173
